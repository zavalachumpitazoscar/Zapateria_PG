# PG Calzados — tienda e inventario

Sistema web responsive para una zapatería. Incluye una tienda pública moderna y un panel administrativo práctico, sin dependencias ni proceso de compilación.

## Funciones incluidas

- Catálogo con búsqueda, categorías, precio, talla y ordenamiento.
- Productos con variantes de talla, stock, etiquetas y promociones.
- Carrito persistente y generación de pedido detallado por WhatsApp.
- Panel de resumen con indicadores y alertas de stock.
- Gestión de productos: crear, editar, eliminar, precios, SKU y existencias.
- Kardex básico de cambios de inventario.
- Configuración del número de WhatsApp y exportación de respaldo JSON.
- Diseño responsive para escritorio, tablet y celular.

## Uso

Abre `index.html` para la tienda y `admin.html` para el administrador.

En el modo demostración local, completa ambos campos del formulario para acceder.

> No hay credenciales publicadas en el repositorio. La autenticación y los datos actuales se almacenan localmente para facilitar la demostración. Antes de usarlo en producción se debe conectar Firebase Authentication y Firestore, definir reglas de seguridad y reemplazar el número de WhatsApp desde Configuración.
